# 🌟 Quozio Clone – Professional Quote Generator & Interactive Feed

A modern, responsive, and visually elegant **Quote Generator** built with **React (Vite)**. Quozio Clone allows users to create beautiful quotes, customize author details, switch between stunning light and dark themes, and manage an interactive quote feed with a smooth user experience.

---

## ✨ Key Features

### 📝 Dynamic Quote Creation

Generate beautiful quote cards instantly by entering your own quote and author name. Every new quote is automatically added to the interactive feed.

### 🎨 Elegant & Modern UI

Designed with a clean, minimal, and professional interface using **CSS Custom Properties**, soft shadows, and modern layouts for an exceptional user experience.

### 🌗 Smart Dark / Light Theme

Experience seamless theme switching with a stylish **3D Neumorphic Toggle Switch** featuring **☀️ Sun** and **🌙 Moon** icons.

* 🌞 Light Theme – Soft pastel background (`#FBEFEF`)
* 🌙 Dark Theme – Rich, professional dark interface
* ⚡ Instant theme transition with smooth animations

### 💾 Persistent User Preferences

Theme selection is automatically saved using **LocalStorage**, ensuring your preferred mode remains active even after refreshing or reopening the browser.

### 📱 Fully Responsive Design

Optimized for every screen size.

* 💻 Desktop
* 💼 Laptop
* 📱 Mobile
* 📟 Tablet

The layout adapts beautifully across all devices.

### ⚡ Fast Performance

Built with **Vite**, providing lightning-fast development, instant hot reloading, and optimized production builds.

### 🧩 Component-Based Architecture

Developed using reusable React components, making the project clean, scalable, and easy to maintain.
